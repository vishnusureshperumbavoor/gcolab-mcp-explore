AI Agent Integration

            
Any AI agent or external service can execute code remotely on Google Colab by calling this local endpoint:

            
            

              cURL Example
              
curl -X POST http://localhost:8000/api/execute \
  -H "Content-Type: application/json" \
  -d '{"code": "import torch; print(torch.cuda.is_available())"}'

            


            

              Python Example
              
import requests

res = requests.post("http://localhost:8000/api/execute", json={
    "code": "!nvidia-smi"
})
print(res.json()["output"])
